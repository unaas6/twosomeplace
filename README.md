# A TWOSOME PLACE 웹사이트

기존 Web-outback 예제의 12개 패널 레이아웃과 반응형 구성을 유지하고, 투썸플레이스 콘셉트로 브랜드 콘텐츠와 디자인을 변경한 프로젝트입니다.

## 실행 방법
- `index.html` 파일을 브라우저에서 엽니다.
- GitHub Pages에 배포할 경우 저장소 최상위 폴더에 `index.html`이 있어야 합니다.

## 폴더 구조
```text
Web-outback-main/
├── index.html
├── css/
│   └── style01.css
├── img/
│   └── twosome/
│       ├── hero.jpg
│       ├── store.jpg
│       ├── coffee.jpg
│       └── ...
└── js/
    └── prefixfree.min.js
```

## 적용 사항
- 브랜드명 및 소개 문구를 투썸플레이스 콘셉트로 변경
- 버건디, 크림, 베이지 중심의 색상 적용
- 커피, 케이크, 디저트, 매장 이미지 교체
- 기존 12개 콘텐츠 패널의 배치 규칙과 반응형 브레이크포인트 유지
- 패널 호버 효과 및 등장 애니메이션 유지

## 참고
Google Fonts와 Font Awesome 아이콘을 CDN으로 불러오므로 인터넷 연결이 필요합니다.
이미지 파일은 프로젝트 내부 `img/twosome/` 폴더에 포함되어 있습니다.
